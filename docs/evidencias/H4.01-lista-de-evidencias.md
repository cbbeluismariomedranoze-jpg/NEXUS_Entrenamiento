# H4.01 — Lista de evidencias para completar en el laboratorio

Este archivo es una guía de captura. **No contiene evidencias simuladas.** Las imágenes deben ser capturadas por el estudiante durante el procedimiento real, con la fecha y hora del sistema visibles.

## Antes de empezar
- [ ] En Windows, abrir Ajustes > Hora e idioma y comprobar que la fecha y hora del sistema son correctas.
- [ ] Dejar visible el reloj de Windows en la barra de tareas en cada captura.
- [ ] Usar capturas propias, consecutivas y sin editar el contenido que prueba la actividad.
- [ ] Guardar las imágenes en esta carpeta y agregarlas al PDF final.

## Capturas obligatorias
1. [ ] GitHub mostrando el repositorio personal antes de clonar.
2. [ ] Visual Studio clonando el repositorio desde GitHub o la carpeta recién clonada con el proceso visible.
3. [ ] Solución original abierta en Visual Studio, mostrando NexusTraining.
4. [ ] Compilación correcta del proyecto de consola H3.
5. [ ] Ejecución funcional del modo de consola original.
6. [ ] Solución con los proyectos NexusTraining y NexusWindowsForms en el Explorador de soluciones.
7. [ ] Código/formulario MainForm.cs y menú gráfico diseñado.
8. [ ] Windows Forms ejecutándose con los botones visibles.
9. [ ] Commit descriptivo en Visual Studio.
10. [ ] Push completado correctamente desde Visual Studio.
11. [ ] GitHub mostrando los archivos NexusWindowsForms y el cambio de la solución.
12. [ ] Clonación del repositorio actualizado en otra máquina o carpeta limpia que no sea la carpeta original.
13. [ ] Solución recién clonada abierta en Visual Studio.
14. [ ] Compilación correcta de la solución recién clonada.
15. [ ] Windows Forms ejecutándose desde la copia limpia.

## Recomendación para el PDF
Portada con nombre del estudiante, materia, H4.01, fecha y repositorio. Después, una sección por etapa con captura, fecha/hora visible y una breve descripción de lo que demuestra. La captura debe mostrar la aplicación real; no dibujar ni reconstruir pantallas para sustituir la evidencia.

## Verificación final
- [ ] Confirmar que el enlace del repositorio es público.
- [ ] Confirmar que NEXUS_Entrenamiento.sln incluye ambos proyectos.
- [ ] Confirmar que la versión de consola continúa disponible.
- [ ] Confirmar que Windows Forms compila y ejecuta desde la clonación limpia.
- [ ] Adjuntar el PDF de evidencias a Moodle y pegar el enlace público de GitHub.
